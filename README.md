A dense, newspaper-style infographic summing up the world news of Tuesday 24 November 2026 in one 1024×1024 image: 40 verified stories across six regions, a UTC timeline strip, a world map with numbered pins, per-story sources with CLAIM/CONFIRMED markers, and a DATE CHECK box listing stories deliberately left out because they broke before Tuesday. The image is drawn by `render.py` (Pillow) and committed as `entry.png`; `main.py` copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
